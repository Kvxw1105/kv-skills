# Composition contract

## Candidate packet

Specialists exchange candidate packets with stable IDs. A packet should include the frame, target user, problem, mechanism, expected outcome, assumptions, constraints, evidence status, lineage, and current disposition.

## Exact return signals

The suite uses exact uppercase signals:

- `REFRAME_ROOT`
- `EXPAND_DIVERSITY`
- `REFRAME_TARGET_USER`
- `SPLIT_USER_PAYER`
- `PRESERVE_CORE_CHANGE_FORM`
- `REDUCE_SCOPE`
- `REVALIDATE_DEMAND`
- `REDESIGN_DISTRIBUTION`
- `USER_GOAL_NONCOMMERCIAL`
- `STOP_NO_OPPORTUNITY`
- `READY_FOR_DECISION`

Each signal must state its reason, preserved fields, invalidated fields, and next owner. Free-form criticism without a routing consequence is insufficient.

## Review independence

Convergence performs blind review and must not inherit generator enthusiasm, self-rankings, or persuasive labels as evidence. Business validation treats the shortlisted direction as a hypothesis and may return it for reframing, transformation, scope reduction, or distribution redesign.

## Noncommercial guardrail

The controller records whether commercial validation is required. When it is false, payer, pricing, revenue, and market-priority fields remain optional and cannot override use value, artistic integrity, learning value, public value, or the user's stated objective.
