# Examples

## Example 1: Rescue an ambitious platform

Candidate: a universal "personal operating system" that models every aspect of a person's life.

Blind diagnosis:

- Strong core: longitudinal context plus decision consistency.
- Weak shell: universal scope, sensitive data, impossible onboarding, unclear test.

Transformation:

- `I-01A`: a weekly decision review that tracks commitments, repeated conflicts, and rule changes for one domain.
- Preserved core: longitudinal memory and consistency checking.
- Signal: `PRESERVE_CORE_CHANGE_FORM`.

## Example 2: Reject novelty theater

Candidate: "Cognitive Black Market", an ordinary prompt marketplace with dramatic branding.

After name removal, the mechanism is a searchable prompt catalog with no new curation, trust, or transaction rule.

Result: Reject. The concept has presentation novelty but no structural difference.

## Example 3: Portfolio selection

Finalists:

- `I-02`: manual diagnostic report, role `immediate_test`.
- `I-05A`: expert rubric converted into an interactive tool, role `differentiated_bet`.
- `I-07`: public case database, role `long_term_asset`.

These are retained because they provide different evidence and asset paths, not because all scored similarly.
