# Creative core extraction

A creative core is the smallest mechanism, relationship, constraint, or rule that remains valuable after the original presentation is removed.

## Common cores

- longitudinal memory;
- adversarial rehearsal;
- ritualized commitment;
- transparent evidence chain;
- expert judgment converted into a repeatable rubric;
- community coordination through shared state;
- deliberate friction that improves judgment;
- invisible work made visible;
- private experience converted into a reusable system.

Do not label a theme or aesthetic as a core unless it changes behavior or value creation.
