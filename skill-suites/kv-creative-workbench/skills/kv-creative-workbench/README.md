# KV Creative Workbench

A control-plane skill that routes a fuzzy idea through reframing, divergence, convergence, commercial validation, and decision without rerunning stable work.

## Who should use it

Use it for complex creative or business decisions that need two or more stages, especially when several specialist skills must share state and return upstream for repair.

## Trigger examples

- Turn this fuzzy education idea into several directions, narrow them, and give me a test plan.
- Use a linked creative workflow to evaluate these product concepts.
- The current project failed. Find the broken assumption and rerun only the necessary stage.

Near miss: "Rewrite this paragraph to sound friendlier." This should use a writing or rewriting capability, not the workbench.

## Workflow

The skill creates an IdeaCase, routes to language ideation, independent convergence, and business validation as needed, then applies return signals and selective invalidation.

## Requirements and limitations

The three named specialist skills improve composition. A compact fallback is bundled when they are unavailable. Runtime auto-triggering and cross-skill discovery depend on the host ChatGPT environment. The skill cannot guarantee a platform-level broadcast API.

## Installation

Upload this packaged `skill.zip` through the ChatGPT Skills interface. For the full workflow, install all four suite packages.

## Privacy

The package contains no credentials or external assets. User business context remains conversation input and is not bundled.
