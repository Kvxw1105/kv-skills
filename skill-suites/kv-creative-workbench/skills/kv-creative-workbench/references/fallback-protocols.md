# Compact specialist fallback

Use only when a named specialist skill is unavailable.

## Language ideation fallback

1. Identify three restrictive terms in the user's wording.
2. Reframe the problem across actor, goal, boundary, medium, and opposite assumption.
3. Generate five candidates that use different mechanisms.
4. Give each candidate an ID, mechanism, user, scenario, value, and key assumption.
5. Do not score feasibility unless requested.

## Convergence fallback

1. Strip persuasive labels and self-rankings.
2. Classify candidates as promote, transform, archive, or reject.
3. Test user fit, creative core, feasibility, value, validation ease, and asset potential.
4. Preserve one testable option and one high-originality option when justified.
5. Return no more than three candidates downstream.

## Business validation fallback

1. Separate user, payer, and beneficiary.
2. Identify pain, urgency, substitute, and switching reason.
3. Define first-user channel, minimum offer, experiment, success threshold, and kill criteria.
4. Mark unsupported market claims as hypotheses.
5. Return a repair signal when the failure belongs upstream.
