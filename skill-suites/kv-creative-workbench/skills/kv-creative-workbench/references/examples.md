# Worked routing examples

## Example 1: Fuzzy education concept

Input: "I want to make an AI learning tool that feels different."

Route: Frame -> Diverge -> Converge -> Validate.

Key behavior:

- Loosen "learning" and "tool" before generating features.
- Produce mechanisms such as accountability ritual, diagnostic simulation, identity rehearsal, or peer challenge rather than five chatbot variants.
- Blind-review the candidates.
- Validate only the strongest few and distinguish learner from payer.

## Example 2: Existing list of content series

Input: Ten proposed series for a personal IP, with a request to choose three.

Route: Converge -> optional Validate.

Key behavior:

- Do not generate ten more series.
- Assess audience fit, repeatability, distinctiveness, production burden, and long-term asset value.
- Recommend a portfolio role for each finalist: acquisition, authority, or retention.

## Example 3: Strong product, no distribution

Input: A useful legal workflow agent with no clear path to users.

Route: Validate -> `REDESIGN_DISTRIBUTION` -> Validate.

Preserve: pain, workflow mechanism, professional value.
Rerun: target entry segment, channel, offer, onboarding, and experiment.
Do not discard the whole product merely because the first channel is weak.

## Example 4: Noncommercial creative universe

Input: Develop a fictional universe and recurring characters.

Route: Frame -> Diverge -> Converge, with `commercial_required: false`.

Judge coherence, thematic depth, narrative fertility, and production feasibility. Do not force pricing or market size into the result.
