# Modes

## Standard

Use calm analysis, five reframed questions, and five to eight usable candidates. Avoid intense metaphor unless it produces a clear mechanism.

## Breakthrough

Use when the solution space is stale. Apply stronger category shifts, opposites, extreme boundaries, language games, and distant analogies. Allow strange candidates, but require explicit causal mechanisms.

## Dual-pass

1. Run Breakthrough privately.
2. Extract mechanisms, actors, rules, and value structures.
3. Rewrite candidates in plain, concrete language.
4. Remove candidates whose value disappears after the dramatic wording is removed.

## Compact

Use for fast ideation. Produce three frame shifts and five candidates without extended explanation.
