# De-dramatization pass

For every breakthrough candidate:

1. Delete its name temporarily.
2. Describe the mechanism in one plain sentence.
3. Identify the actor, action, feedback loop, and value.
4. Ask whether the concept remains distinct without the metaphor.
5. Restore a name only after the mechanism survives.

Remove:

- inflated claims;
- forced conflict;
- mystical causality;
- vague transformation language;
- decorative complexity;
- claims that the concept is revolutionary without evidence.

Preserve:

- unusual category shifts;
- new incentive structures;
- useful constraints;
- changed user behavior;
- novel combinations with clear causality.
