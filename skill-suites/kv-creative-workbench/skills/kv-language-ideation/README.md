# KV Language Ideation

A creative framing skill that changes restrictive questions and generates ideas that differ by mechanism rather than naming or surface features.

## Who should use it

Use it for brainstorming, product and content concepts, naming systems, research-question reframing, or creative blocks before feasibility analysis.

## Trigger examples

- Reframe my phrase "AI learning tool" and open several non-obvious directions.
- These ideas all feel ordinary. Use stronger language and boundary reconstruction.
- Generate distinct creative mechanisms without judging business feasibility yet.

Near miss: "Which of these five mature products has the best unit economics?" This belongs to convergence and commercial validation.

## Workflow

The skill detects hidden frames, loosens decisive terms, creates materially different questions, generates candidate packets, and optionally runs a breakthrough plus de-dramatization pass.

## Requirements and limitations

No external tool is required. Current facts should not be invented; market validation belongs downstream. The skill can operate alone or inside IdeaCase v1.0.

## Installation

Upload the packaged `skill.zip` through the ChatGPT Skills interface.

## Privacy

The package contains no credentials, private data, scripts, or external assets.
