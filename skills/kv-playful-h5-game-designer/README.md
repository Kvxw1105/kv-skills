# 轻趣 H5 游戏设计师

一个可中文调度的移动端 H5 轻游戏设计与迭代 Skill。它把本项目在拼词游戏中验证过的手机一屏适配、状态分离、平滑撤回、提示锁定、音效触觉、动态色彩和日夜模式沉淀为可复用工作流。

## 安装

```bash
npx skillkit add Kvxw1105/kv-playful-h5-game-designer
```

## 调度示例

```text
用轻趣 H5 游戏设计师，做一个每天 12 题的成语重组游戏，保持小而美、手机一屏显示、带黑夜模式和按键反馈。
```

## 在线示例

仓库启用 GitHub Pages 后，可在项目站点的 `/playful-h5/` 路径试玩 starter。
