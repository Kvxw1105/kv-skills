# 视觉与交互规范

## 视觉骨架

- 顶部：品牌与弱控制项。
- 上部：进度可视化，尺寸应克制。
- 中部：题号、时间或核心状态，为第一视觉中心。
- 下部：答案槽与主要交互对象。
- 底部：提示、清空、提交等辅助动作。

## 推荐尺寸

- 主内容最大宽度：430–520px。
- 触控目标最小：44×44px。
- 字母按钮：根据数量动态布局，常见 64–88px。
- 主要数字：56–88px，矮屏按高度压缩。
- 页面使用 `overflow: hidden` 时，必须确保关键按钮不会被浏览器栏或安全区遮挡。

## 动效

- 按压：80–140ms。
- 元素进入/撤回：160–260ms。
- 正误反馈：300–550ms。
- 页面状态切换：不超过 650ms。
- 优先使用 `transform` 和 `opacity`，减少布局抖动。
- 撤回时保持可追踪轨迹；批量清空使用 20–60ms 交错，不要瞬间清空。

## 色彩

- 基础背景使用暖白、低饱和浅色或深灰黑。
- 正确色与错误色必须在日夜模式都可读。
- 进度变化可驱动背景色相缓慢变化，但不要快速闪烁。
- 选中状态需同时依靠颜色、明度或形态变化，不能只靠颜色。

## 字体

- 轻游戏优先现代无衬线、圆体或粗体系统字体。
- 避免细衬线造成文艺、杂志或传统文化气质，除非主题需要。
- 中文标题不宜过细；英文大写可适度紧凑。

## 声音

- 点击声：短、脆、轻。
- 撤回声：更短、更轻，体现回弹。
- 正确声：明亮上扬，0.25–0.7 秒。
- 错误声：低沉但不压迫，0.15–0.4 秒。
- 提示声：清楚但不比正确声更奖励。
