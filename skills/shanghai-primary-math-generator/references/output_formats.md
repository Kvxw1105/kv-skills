# 标准输出格式

## 学生版试卷结构

标题：上海小学数学逻辑思维提高练习卷
副标题：适用：二年级下复习 / 二升三衔接 / 逻辑思维拓展
信息栏：学校、班级、姓名、学号
考试栏：建议用时、满分、得分、家长签字
提示语：本卷用于拓展练习；先读题，再画图、列表或分步计算。

题型建议：

1. 周期与规律
2. 搭配与分类
3. 数位与条件推理
4. 时间、方向与生活应用
5. 综合逻辑挑战

每题后预留答题线。复杂题可留两行以上。

## 教师版结构

标题：上海小学数学逻辑思维提高练习卷｜参考答案与解析
内容：

- 命题口径
- 分值建议
- 每题答案
- 简短解析
- 易错点或讲评建议（可选）

## 分值规则

默认满分100分。可按题目难度分配：

- 基础逻辑题：4-5分
- 中等逻辑题：5-6分
- 综合挑战题：6-8分

必须确保所有小题合计为100分。
