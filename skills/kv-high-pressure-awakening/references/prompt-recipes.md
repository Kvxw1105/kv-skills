# Prompt Recipes

## 1. Create one atomic short video

```text
Use the High-Pressure Awakening Engine to write one original Chinese motivational voiceover.

Topic: [topic]
Audience state: [specific current state]
What they say they want: [desire]
What they actually do: [observable contradiction]
Hidden fear: [fear or protected fantasy]
Named enemy/mechanism: [optional; create one if useful]
Primary image system: [door / mirror / time / war / forging / cage / hunt]
Voice: [Grayce / Xinwu / Xuanqi / neutral]
Pressure level: [1 cold / 2 hard / 3 battlefield]
Length: [40-90 seconds]

Use one complete seven-stage loop: seize explanation, mirror behavior, name self-deception, show the future prison, open a remaining door, give one verifiable action, and end with identity change.

Use one enemy, one fear, one image system, one future loss, and one action. Add a new reward every 12-20 seconds. Attack behavior and self-deception, not illness or dignity. Do not glorify injury, sleep deprivation, reckless risk, or permanent overwork.
```

```text
3. named mechanism;

6. best voice adapter.

Finally write the strongest [number] finished voiceovers in original wording.
```

## 3. Create a long high-pressure speech

```text
Write a [minutes]-minute Chinese motivational voiceover using multiple High-Pressure Awakening atoms.

Core theme: [theme]
Audience: [audience]
Voice: [voice]
Pressure level: [level]

Sequence the speech through: excuse, observable behavior, hidden fear, time cost, meaning of pain, identity, choice, and immediate action. Each section must introduce a new psychological layer and begin with a line that could function as a standalone short-video hook. Reopen attention every 30-60 seconds. Do not extend length through synonym repetition.
```

## 4. Xuanqi inside/outside version

```text
Use the High-Pressure Awakening Engine with the Xuanqi adapter.

Topic: [topic]
Audience state: [state]
Hidden causal problem: [problem]

Use the “门外人/门内人” motif as a difference in perception, causality, responsibility, and choice. Do not imply fake secret information. Keep commands sparse. Let Xuanqi reveal the true question or causal structure; let the mortal retain the final choice. Use door, threshold, sleep, light, shadow, or cause-and-effect imagery. End after opening a threshold, not after issuing a productivity checklist.
```

## 5. Grayce execution version

```text
Use the High-Pressure Awakening Engine with the Grayce adapter.

Topic: [topic]
Avoided task: [task]
Deadline: [deadline]
Evidence required: [visible result]

Write in short, tactical sentences. Expose the excuse, calculate the cost, remove low-value actions, set one deadline, and demand one verifiable output. Use wolf-pack, hunt, battlefield, track, or weapon imagery sparingly. Preserve realistic risk control and recovery.
```

## 6. Xinwu lived-struggle version

```text
Use the High-Pressure Awakening Engine with the Xinwu adapter.

Topic: [topic]
Relapse scene: [specific scene]
What the old self says: [reasonable excuse]
Cost of acting: [cost]

Write through an ordinary person's struggle. Use natural Chinese, rough honesty, and one concrete choice. Do not make the narrator permanently heroic or all-knowing. The climax must be an action taken despite relapse, not a speech about becoming invincible.
```

## 7. Rewrite a weak draft

```text
Rewrite the draft with the High-Pressure Awakening Engine.

Preserve its intended meaning. Repair:
- vague opening;
- abstract scolding;
- repeated conclusions;
- missing hope rebound;
- multiple competing actions;
- generic identity ending;
- mixed imagery;
- role voice confusion.

Return the revised script first, then a compact note naming the three biggest structural changes.
```


## 8. Mine explosive mother lines from a source

```text
Analyze the following motivational source with the Golden-Line Mining module of the High-Pressure Awakening Engine.

Do not simply quote the loudest sentences. Extract the psychological mechanism behind each section and rebuild original explosive mother lines.

For each retained line provide:
1. original mother line;
2. hook function: explanation seizure / self-deception exposure / future loss / pain reversal / identity pressure / hope rebound / causal reversal / image strike;
3. why it creates an open loop;
4. best expansion route: mirror / future / mechanism / story / Xuanqi threshold / Grayce execution;
5. best voice: Grayce / Xinwu / Xuanqi / neutral;
6. the distinct short-video topic it can generate.

Score candidates for personal implication, reversal, open loop, spoken rhythm, expansion capacity, and originality. Keep only lines that can support at least three new layers. Deduplicate lines that express the same psychological conflict.

Then select the strongest [number] lines and expand each into a 40-90 second original voiceover. Do not preserve distinctive source wording or unsupported autobiographical claims.

```

