## 1. 先定义视觉命题

在写 CSS 前，用一句话描述作品的视觉命题：

`<情绪> + <材质/媒介> + <核心形状> + <动态特征> + <克制原则>`

示例：

- 安静神秘 + 深色纸张 + 太极猫眼 + 微弱呼吸光 + 少装饰。
- 轻快聪明 + 奶油底色 + 大字母方块 + 弹性位移 + 清楚优先。

抽象词必须落成可实现参数：

- 高级 → 低色数、稳定层级、精确留白、克制阴影。
- 炫酷 → 一个主动态效果、强暗部、局部高亮、有限速度。
- 可爱 → 圆角、柔软弹性、温和声音；避免贴纸堆叠。

## 2. 反模板化约束

默认避免：

- 通用紫蓝渐变背景；
- 所有卡片玻璃拟态；
- 同样大小的圆角矩形铺满页面；
- 无内容意义的光球、网格和粒子；
- 图标、标题、按钮都抢视觉焦点；
- 深色卡片里使用低对比灰字；
- 只靠字体变大建立层级。

一个页面最多保留一个主视觉焦点、一个主要动效语言和两级强调色。

## 3. 设计令牌

建立共享变量，不在组件中散落魔法数字：

```css
:root {
  --bg: #f5f3ef;
  --surface: #ffffff;
  --text: #171717;
  --muted: #6f6f6f;
  --accent: #ff6b35;
  --danger: #c94a43;
  --radius-sm: 10px;
  --radius-md: 18px;
  --radius-lg: 28px;
  --space-1: 6px;
  --space-2: 10px;
  --space-3: 16px;
  --space-4: 24px;
  --shadow-soft: 0 12px 30px rgba(0,0,0,.08);
}
```

颜色、字号、间距、圆角、阴影、动画时长都应有令牌。暗色模式单独校准，不做简单反色。

## 4. 对标转译

拆解对标作品的：

- 第一眼焦点；
- 形状语法；
- 留白密度；
- 色彩比例；
- 操作反馈；
- 动画节奏；
- 结果页传播结构。

只迁移底层规律。至少改变题材、核心动作、品牌语言、视觉资产和结果结构中的三项。

## 5. 不同人群

年轻人和儿童：

- 入口更直接；
- 文字更短；
- 点击目标更大；
- 成功反馈更清楚；
- 不使用低对比、复杂菜单和长说明。

上班族或专业用户：

- 减少幼稚装饰；
- 提高信息密度但保留层级；
- 结果应有解释价值，不只给称号。

## 6. 验收

检查：

- 缩成 25% 缩略图时，主焦点是否仍清楚；
- 黑白查看时，层级是否仍成立；
- 去掉背景动效后，页面是否仍有设计；
- 每个装饰是否服务于情绪或操作；
- 是否一眼像常见 AI 模板；
- 手机与电脑是否保持同一视觉语言，而非同一排版。
