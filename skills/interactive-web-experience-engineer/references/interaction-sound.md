# 交互、动效、声音与触觉

## 反馈矩阵

为每个高频动作定义：视觉变化、声音、触觉、时长、是否可叠加和失败降级。

| 动作 | 视觉 | 声音 | 触觉 | 原则 |
|---|---|---|---|---|
| 点击 | 轻压缩后回弹 | 20-60ms 短音 | 可选轻触 | 低延迟 |
| 选择 | 状态颜色与位移 | 清脆短音 | 轻触 | 可追踪 |
| 撤回 | 沿原路径退回 | 更低的回收音 | 无或轻触 | 不瞬间消失 |
| 提示 | 锁定与柔和高亮 | 双音提示 | 单次轻触 | 不替玩家完成全部 |
| 正确 | 聚合、上扬、释放 | 明亮上行 | 成功节奏 | 不刺耳 |
| 错误 | 短促晃动或边框 | 低、短、克制 | 短震 | 不羞辱 |
| 连击 | 强度逐级增加 | 音高递进 | 节制使用 | 防声音堆积 |
| 结算 | 内容分层出现 | 0.4-1.2s 乐句 | 可选 | 结果可截图 |

## 动效规则

- 动画解释状态变化，不只装饰。
- 元素应有来源和去向。
- 高频动效 80-180ms；状态过渡 180-320ms；结算可更长。
- 支持 `prefers-reduced-motion`。
- 动画结束必须清理临时 class 和锁定状态。
- 快速连续点击不得因异步回调删除错误元素。

## 声音规则

- 首次用户手势后解锁 AudioContext。
- 高频声音短、轻、可中断；限制并发和冷却。
- 播放库解决兼容性，不能改善素材本身音色。
- 外部音频必须记录来源和许可证。
- 无素材时可用 Web Audio 合成简单包络，不生成刺耳长音。
- 提供声音开关并本地保存。

## 触觉规则

- 触觉是增强层，不承担唯一关键信息。
- iOS 浏览器可能不支持 `navigator.vibrate`。
- 对儿童和高频点击场景减少震动频率。
