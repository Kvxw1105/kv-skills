# 质量验收矩阵

## 核心路径

进入 → 开始 → 核心操作 → 撤回/清空 → 提示 → 正确 → 错误 → 超时 → 下一局 → 结算 → 再玩。

按产品裁剪，但不能只测试成功路径。

## 尺寸矩阵

至少覆盖：

- 320×568
- 390×844
- 430×932
- 640×360
- 768×1024
- 900×600
- 1024×768
- 1366×768
- 1700×864
- 1920×1080

再检查浏览器缩放 80%、100%、125%、150%，侧栏、横竖屏变化和深浅主题。

## 自动或人工检查

- `scrollWidth <= clientWidth`；
- 核心元素无重叠；
- 关键按钮可到达；
- 触控目标不低于 40px，移动端重要按钮接近 44px；
- 文本不突破容器；
- 固定层不覆盖正文；
- JS 控制台无错误；
- 外部资源失败时仍可用；
- 快速点击不会触发竞态；
- 音效首次手势后可播放并可关闭；
- `prefers-reduced-motion` 可用。

## 视觉验收

- 主焦点明确；
- 宽屏有效利用空间；
- 窄屏不拥堵；
- 暗色模式对比清楚；
- 动效不造成布局跳动；
- 结果页适合截图；
- 页面不呈现通用 AI 模板感。

## 诚实报告

分为：已测试通过、测试失败并已修复、无法测试、仍有风险。没有运行浏览器时不能写“全面适配通过”。
