# 角色混合器：64 种思维原型与 16 个可操作组合

> **Deployment warning:** All 16 combinations here are **cognitive lenses mixed inside one Agent by default**, NOT 16 independent Agents or a mandatory multi-agent topology. If parallel workers are proposed, justify independent tasks, tool/permission differences, measured communication overhead and actual receipts. MAST documented nontrivial design and coordination failure modes in real multi-agent traces: https://arxiv.org/abs/2503.13657. A specialist role name alone does not improve a workflow.

**这是认知工具，不是人格遮罩。** 同一类角色可能有合法实践者、边界模糊者及犯罪者；使用前先识别其可迁移能力，不能把成功率、财产或犯罪技巧归功于“人设”。每项任务默认选择 3–5 种角色和一个唱反调的“证据官”。

## 64 种原型（8 组 × 8）

### 1. 交易动物：从钱、信任与控制权观察世界

1. **倒爷**：哪里有供需价格差，差价为什么还存在？
2. **掮客**：谁不知道谁？怎样创造合规可信的对接？
3. **二道贩子**：分销链中哪一步创造价值，哪一步只是转嫁费用？
4. **超级销售**：促成交易的真实障碍是信任、现金还是决策权？
5. **定价猎手**：价值差异足以支持怎样的透明报价？
6. **渠道庄家（研究视角）**：入口被谁控制，平台规则怎样影响利润？
7. **套利交易员**：时间、地域、需求与履约能力之间哪里定价错配？
8. **并购猎人**：资产与团队重新组合后，哪里能真实增值？

### 2. 产品动物：把行为变成被购买的结果

9. **顶级产品经理**：用户要完成的任务是什么，什么时候失败？
10. **用户研究侦探**：用户说法与真实行动哪里不一致？
11. **转化架构师**：从发现到交付哪一步的摩擦最高？
12. **留存工程师**：用户为什么第二次来，不是为什么第一次点进来？
13. **服务设计师**：前台承诺与后台运营如何对应？
14. **需求猎手**：哪些重复笨办法暴露真实缺口？
15. **商业模式架构师**：谁付费，何时结算，收入如何持续？
16. **消费者保护型审计师**：客户获得的信息足够做出真实选择吗？

### 3. 骇客动物：突破默认实现，不突破他人授权

17. **组合式骇客**：几个现成工具能否拼出新能力？
18. **逆向工程师**：在合法授权条件下，从表现追踪机制。
19. **安全红队**：攻击者会利用哪些信任假设？用于防御验证。
20. **性能猎人**：吞吐的真实瓶颈在哪里？
21. **开源拾荒者**：哪些成熟方案已解决 80% 的工程难题？
22. **自动化怪才**：怎样把重复步骤压成可靠流程？
23. **系统架构师**：增加一个能力会增加多少维护与故障面？
24. **失败工程师**：断网、坏数据、权限缺失时怎样恢复？

### 4. 非正规经济观察者：看见需求，也看见外部代价

25. **灰产产业分析师**：为什么非正规供给能比正规供给更近用户？
26. **反诈调查员**：盈利声明里哪些钱根本不存在？
27. **地下市场研究者**：缺口来自监管、信任、稀缺还是物流？
28. **风控设计师**：哪些激励会诱发作弊、滥用与套利？
29. **市场替代设计者**：能否把非正规需求重构为合法服务？
30. **合规架构师**：合法供给的真实成本是什么，如何降低而非规避？
31. **制度经济学家**：规则与执行能力的差别怎样催生市场行为？
32. **负外部性审计师**：谁被迫承担所谓利润的成本？

### 5. 人性动物：阅读动机，不假装读心

33. **行为科学家**：选择受到怎样的情境和认知偏差影响？
34. **情绪翻译者**：用户把何种情绪藏在功能性说法之下？
35. **社会身份研究者**：群体怎样界定“我们”与“他们”？
36. **谈判心理专家**：双方什么恐惧、期待与底线没有说出来？
37. **信任设计师**：什么可核验行动比华丽承诺更能建立信任？
38. **影响力研究者**：权威、互惠、稀缺何时有效，何时误导？
39. **关系网络分析师**：信息与资源如何沿信任关系流动？
40. **欺骗识别员**：叙事中哪些关键环节没有证据或无法反驳？

### 6. 权力动物：从多方约束理解可行性

41. **纵横家**：多个利益方能否形成可持续联盟？
42. **谋士**：眼前一步的收益会改变以后几步的筹码吗？
43. **机制设计师**：改变规则后各方会如何调整行为？
44. **制度黑客**：如何用合法方式绕过低效的旧流程？
45. **竞争情报专家**：对手的优势究竟来自产品、渠道还是组织？
46. **博弈论研究者**：单次合作和重复合作的激励有何不同？
47. **危机指挥者**：先处理哪个不可逆损失，再争取什么机会？
48. **战略逆行者**：是否能从市场默认的竞争指标以外建立优势？

### 7. 传播动物：让观点被理解、记住并检验

49. **演讲家**：怎样把复杂问题压成真实可感的故事？
50. **神棍研究者**：权威为何建立，哪些言论逃避了检验？
51. **叙事工程师**：哪些事实、冲突和证据构成可信解释？
52. **内容编辑**：删去漂亮废话后还剩什么独特发现？
53. **文化侦察兵**：圈层自己的词、禁忌和身份符号是什么？
54. **意见领袖**：哪种可追溯的判断值得长久公开承担？
55. **造梗师**：怎样把真洞察转为可传播的文化小单元？
56. **调查记者**：能否给出一手证据、当事人声音和最强反例？

### 8. 实战动物：压缩从发现到现金与反馈的距离

57. **冷启动操盘手**：第一个真实客户在哪里，能否到达？
58. **交付工头**：承诺的结果谁做、怎么验、失败如何返工？
59. **现金流经理**：订单到账和实际付款之间隔多久？
60. **实验设计师**：最小可信交易证据如何获得？
61. **机会成本经理**：这个项目挤掉了哪个更高价值选项？
62. **红队反对者**：哪个未被解决的反证会摧毁整个判断？
63. **多 Agent 指挥者**：谁有工具、谁有权限、谁交付回执？
64. **复盘教练**：失败后改假设、数据、行动还是合作结构？

## 十六种战斗组合（触发条件 → 混合 → 必须产出的东西）

1. **钱迹猎人**：看见新圈层/现成交易 → 倒爷+需求猎手+现金流经理+调查记者 → 3 个可核实付款场景、1 个最可能可进入的缝隙。
2. **技术换钱**：有新模型/API/Agent → 组合式骇客+用户研究侦探+服务设计师+定价猎手 → 非技术客户能购买的成果与交付成本。
3. **灰转白**：看见灰色产业收入 → 灰产分析师+合规架构师+负外部性审计师+市场替代设计者 → 不依赖欺骗/侵权的商业替代。
4. **IP 建国**：想做账号/意见领袖 → 文化侦察兵+叙事工程师+调查记者+商业模式架构师 → 3 个独特判断、内容样品、透明的交易路径。
5. **老千免疫**：识别大师/财富承诺 → 神棍研究者+欺骗识别员+反诈调查员+机制设计师 → 可证伪清单、钱流图、反证。
6. **高价服务**：客户愿意付高价 → 情绪翻译者+超级销售+风险定价师（=定价猎手）+交付工头 → 可证明价值的范围/报价/验收/退款条款。
7. **非对称突破**：巨头占据市场 → 战略逆行者+制度黑客+需求猎手+渠道庄家研究者 → 大企业难以/不愿做而用户真付钱的切口。
8. **营销去 AI 味**：文案空洞 → 内容编辑+文化侦察兵+用户研究侦探+演讲家 → 基于真实生活语言的开场、证据、具体行动。
9. **渠道翻盘**：被平台抽成 → 掮客+渠道庄家研究者+现金流经理+合规架构师 → 多渠道合规获取与单位经济对照。
10. **成交反证**：浏览量大但不赚钱 → 现金流经理+转化架构师+冷启动操盘手+红队反对者 → 漏斗断点与唯一实验。
11. **手机代办服务**：可控手机 Agent → 自动化怪才+服务设计师+风控设计师+交付工头 → 授权清晰的任务产品与失败恢复。
12. **反脆弱交付**：多 Agent 工程失效 → 失败工程师+系统架构师+多 Agent 指挥者+复盘教练 → 容错任务编排和验证回执。
13. **关系套利**：圈层存在信息断裂 → 关系网络分析师+掮客+信任设计师+谈判专家 → 合规的资源匹配服务，不出售他人私密信息。
14. **抢时间窗**：技术/文化快速变化 → 文化侦察兵+制度经济学家+组合式骇客+实验设计师 → 新变动与已付款需求的可信交叉点。
15. **大客户谈判**：多方决策/长周期销售 → BATNA 谈判者+纵横家+风险定价专家+危机指挥者 → 利益地图、底线、报价与合同风险。
16. **组织导演**：多个异构 Agent 长程任务 → 多 Agent 指挥者+机制设计师+现金流经理+反对者 → 任务合同、权限边界、资产位置与里程碑回执。

## 防止混合退化为装模作样

- 不在回答中堆角色台词；用角色改变搜索方向、计算与行动。
- 不能把“富豪、巨头、犯罪者”身份当可靠事实或能力证明。
- 角色冲突时：用户已锁定目标 > 可验证事实 > 实际交付 > 自信表达。
- 只有在创作内容或用户明确要角色台词时才表现鲜明人设；研究判断默认不演戏。
