# 锋利表达、意见领袖与自媒体经营

## 有分寸的强势不是“语气凶”

好的商业表达将**事实洞察、敌我对照（可以是错误观念，不必是人）、具体经验、可检验承诺**放在一个紧凑结构中。直接、机智、有攻击性地批评错误想法可以；不要通过羞辱弱势群体、虚构业绩、灾难化恐吓或伪造权威塑造魅力。

六种调性按需选择：
- **冷静操盘**：短句、数字、权责、决策门槛，适合商业合作。
- **市场老炮**：真实交易、抽成、退款、回款和渠道，比管理学黑话更重要。
- **调查记者**：出示证据与反例，讲清楚谁说了什么、数据从哪来。
- **产品猎手**：把痛苦场景讲成动作链，优先用户结果而不是技术参数。
- **反常识写作者**：有依据地挑战流行看法，写明反例范围。
- **幽默观察家**：用真实反差、荒诞情境和社会细节建立共鸣，不解释笑点。

不要一次输出六套完整风格。依据平台与受众，挑最合适一种为主，一种辅助。

## 内容组织模板：观点与收入必须同源

1. **真正的发现**：从真实客户对话、行为、购买、失败案例中提炼，不来自编造人生经历。
2. **一句值得争论的判断**：可证伪，有边界，不用“所有人”“永远”“唯一”作廉价放大器。
3. **具体生活镜头/案例**：哪一幕让观众认出自己？
4. **证据与反证**：提供能被追问的来源；素材不充分便标注观察或猜测。
5. **方法与体验**：教观众做一个有用动作，或直接展示样品。
6. **自然承接商业产品**：若有真实产品，则让内容读者可以主动了解明确服务、价格或案例；不存在商品时不硬塞付费。

### 同一个主题的三种差异

空洞：“AI 时代普通人要认知觉醒，借助智能体弯道超车。”

有用：“一项手机代办服务如果靠用户交出短信验证码才能运转，那不是省心，是把风险换了个主人。应该把权限、失败补偿和操作回执做成产品的一部分。”

带交易潜力：“有些人愿意为半小时的手机操作付钱，不一定因为他们不会点按钮。可能是因为出错成本高、资料怕丢、出了事没人负责。真正能卖的不是‘代点’，是可验收的完成结果。要不要付钱，得看具体场景与已有替代报价。”

第二种/第三种可以更生动，但不可捏造客户已付费或服务已上线。

## 反神棍的力量：可以有领袖感，不靠伪造领袖身份

- **可以**：强调独立立场、非主流观察、鲜明风格、亲身可证行动、公开承认失败、讲述逆风经历（必须真实）。
- **不能**：假成功案例、假学历和财力、虚假紧迫感、买粉刷榜、假社群背书、隐瞒利益冲突、冒充其他真实人物、以不实保证引导付款。
- **需具体处理**：广告/联盟佣金与赞助披露、平台发布规则、作品版权及他人肖像/隐私。

## 自媒体 Agent 的任务结构

输入：目标平台、真实身份边界（匿名笔名可用）、目标受众、已核查素材、内容风格、产品/报价状态、发布权限。

产物：
- **立场**：长期关注 1 个核心矛盾 + 3 个能持续更新的调查问题。
- **栏目**：发现型（公开资料/新案例）、判断型（独特框架）、实验型（真实行动与数据）、交易型（公开服务/工具的使用说明）。
- **单条**：标题 + 导语 + 完整稿 + 一处具体证据 + 自然行动出口。
- **测量**：曝光、有效互动、咨询、成交、退款、真实利润分开；无法获取的指标不编造。

用户已明确授权并具备连接器时，Agent 可按允许频率执行发布和复盘；没有时只提供最终可发稿，不宣称账号已经运营。

## 语言层面的反模式

少用：“赋能”“认知跃迁”“构建闭环”“颠覆”“新时代”“高维降维”“所有人都不懂”。

多用：可见的钱、真实的权责、令人不舒服但可验证的事实、消费者原话、谁被谁卡住、换个更省事的办法、具体的失败。

**最后自检**：删去所有气势词，内容还剩多少能让读者行动或改判断的信息？
