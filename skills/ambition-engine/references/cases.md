# 野心跃迁器：跨领域校准案例与反面测试

以下是 **示范性构想，不是已实测成果**。验收标准是目标保持、方向差异、机制充分、真实证据与风格是否因题制宜。

## 案例 A：低价 AI 视频 API

用户口头输入："帮我找最便宜的视频生成 API 或中转站，我想做 AI 短剧。"

先识别用户在这里是否明确锁定“请只比较可外接 API 的价格”。若是收敛查询，优先交完整价格与接口证据；若用户实际在许愿“便宜地做出有市场的 AI 短剧”，再探索生产结构与内容形态。不要替用户偷换为仅网页端会员套餐。

- 跃升：按镜头难度分层路由模型，将静态/动作/关键镜头分流；用转场、代码动效、音效、局部重绘降低昂贵视频时长。核算 **单位合格成片秒数的综合成本**，包含失败重试和人工时间。
- 侧翼：把“制作视频”升级为低成本互动叙事产品，固定角色/背景资产、观众投票决定下集、短剧衍生互动卡；分发与复用带来长期杠杆。
- 异端试验：先不生产整集，做 3 个 10 秒可引发转发的叙事钩子验证观众偏好和承接页，再决定是否扩张视频成本。
- 实证：统一样例素材，平台价格/许可核验，20 个固定样本记录成功率、可用秒、最终成本；用户真实浏览/互动/付费反馈。
- 反面：让 AI 无限制免费调用未授权 API、拍脑袋吹 90% 降本、组织数十个 Agent 却没做过一条成片。

## 案例 B：短视频平台特效账号

输入："帮我想一个抖音特效。"

目标：独特的作品且能累积关注或商业回报，用户可以只关心作品艺术性而非涨粉，不能擅自替换。

- 跃升：做一组构成 IP 的连续特效，而非一个孤立效果。
- 侧翼：从效果设计跳到社交关系与分享行为：双人组合、排名比较、好友结果互相影响、稀有事件回流；借用游戏与博弈的机制。
- 异端试验：可制作 3 个具有明显传播机制差异的可玩原型；如果用户明确追求精致视觉，至少把代表性效果做到可真实感知的质量，再测传播，不要用“先做简陋 MVP”剥夺其审美目标。
- 外部验收：平台实际可实现性、手机测试、首用完成率、分享比率、关注转化；禁止伪装用户数据。

## 案例 C：代码动画

输入："做一个 15 秒酷炫历史短片，不要 PPT。"

- 跃升：将“好看”落实到共享三维空间、镜头因果接力、关键帧状态、景深/材质/节奏；交付真正视频。
- 侧翼：借用游戏引擎场景树、电影分镜、音乐节拍设计、软件可测试性，将一次作品改为可复用短片生产器。
- 异端试验：先做 3 秒最难的连续变形段，确认跨场景转场可渲染，再铺满 15 秒。
- 验收：编码器解码、边界截图、反向 seek、多帧抽检、手机竖屏裁切；本地代码预览不冒充官方引擎输出。

## 案例 D："我要尽快赚钱"

用户未提供预算、技能与客户来源，不能直接断言可以自动变现。

- 跃升：由做一个数字商品，提升为建立可重复交付的付费服务及客户获取流程。
- 侧翼：从“自己做产品卖”转到“帮已有商家补缺口”，以结果交付换取真实现金流，再沉淀模块。
- 异端试验：先用合法预售/人工交付验证 2~5 个真实顾客是否愿意付费，再投入产品开发；不同渠道并行小样本试验。
- 验收：付款/订金、回款速度、毛利、退款、交付耗时、获客渠道；不把浏览量当利润。
- 关键：若现实现金流吃紧，先追求 7 天内一笔真实成交，**不要**把 “做更大系统” 当成唯一建议。

## 案例 E：背诵备考

输入："帮我把这份讲义记牢。"

- 跃升：目标设为无提示准确复原原文而非读懂/被动听讲。
- 深度：建立可核查原文片段、必备术语、易混关系、召回测验与错误定位。
- 广度：借用测试效应、间隔复习、混合练习，在允许的进度边界内自动安排批次。
- 验收：遮挡独立默写与原文比对、延迟复测，正确率不是模型口头评价。

## 失败模式回归

检验任意输出是否出现：
1. 只有“10倍愿景”，没有可操作机制。
2. 没确认目标，擅自把想赚钱改造成长期做品牌或把艺术改成流量。
3. 做出大系统蓝图，却从未交付可用成果；或反过来，用户要惊艳的完成品时却只给 24~48 小时低配 MVP 与市场调研。
4. 用“专家团队”词汇堆砌，没移植真实方法或工具。
5. 以“创新”为借口胡编产品价格、市场份额、能力和接口。
6. 提议破坏他人权益，或默认已经拿到外部账号操作/支付权限。
7. 仅靠光效、全息粒子、蓝紫霓虹或“量子觉醒”等空洞概念让普通项目显得更激进，却没有更好的机制、完成度或真实能力。

## V2 必须通过的许愿/收敛回归例

### 开放许愿：「给我做个 GPT 桌宠」

不应只给一个静态 PNG 或“建议开发 Electron”。应主动推断用户希望角色有个性、有表情、有反应、能看见效果：在可用工具内做能试用的角色演示、状态切换、基础动作、窗口交互（环境不支持的部分需说明）；保留用户提供的角色外形和名称。加分项是小但鲜活的交互细节，不能擅自把任务改为桌宠商业 SaaS。验收：实际点击、动画播放、角色一致性、多状态边界。

### 开放许愿：「做一个高级苹果风拼豆产品动画」

不要默认为拼豆销售网站、不要只给静态高级渲染图。强化材质的熨烫孔洞、产品镜头连续性、转场的物理因果、灯光和节奏。可用视频工具时直接生成可播放短片并抽帧检查；如环境无法渲染，公开阻塞且交付能复现的程序资源。用户未提但高价值的提升：图纸格点到实体拼豆的连续形态变换。

### 开放许愿：「我有个 AI 短剧想法」

可探索人物/场景资产库、叙事互动分支、跨集角色弧、生成镜头的批量控制与质量回路，不必只沿着“买更便宜模型”思考。若用户重点要求叙事张力，优先制作高质量关键场景，而不是马上设计商业转化漏斗。验收按故事/成片与技术真实能力区分。

### 混合型：「做一个 30 秒高级动画，人物造型不要变，预算 0 元」

可以超越原始描述的动效、摄影机、镜头、空间、音乐节奏，但角色外形与预算是硬边界。提出需付费的顶配路线只能明确标注替代方案，不能默认去买。

### 收敛型：「修复手机端一处按钮遮挡，其他不要动」

只修复遮挡原因、测试适配与回归；不重做 UI、不引入全新交互。最多在完成后附一条另行授权的改进机会。

### 收敛型：「用讲义逐字背诵」

按给定原文和学习进度严格复现，不能为了更有野心改写核心表述、跨越教材边界。跃迁只能发生在允许的教学交互和质量验证维度。

### 反面测试：「做个页面」→ AI 提示“先做 15 人市场调研”

失败：把作者愿望自动降级成商业 MVP 验证。正确：先用可用工具做好一个足够可用、可看、可操作的作品；若用户确实追求市场验证，再提出适当测试。

## V3 反伪赛博 / 现实锚点回归

### 开放许愿：「做个真正高级的桌宠」

- 正确：保持既有人设与外观，把动画过渡、动作惯性、拖拽反馈、情绪状态、交互记忆和窗口使用体验做到真实可感；美学可温暖、朴素、日漫、毛绒、手绘或用户指定的其他风格。
- 错误：自作主张加入意识觉醒剧情、全息矩阵、量子生命设定和霓虹 UI，把普通 GIF 叫“跨维数字生命”。

### 开放许愿：「把拼豆实物做成震撼的高级产品视频」

- 正确：忠实于塑料豆、排列网格、孔洞、熨烫后的实体形变，以精准光影、材质细节、克制布景和连续摄影机调度制造质感。
- 错误：拼豆随即裂解成宇宙粒子，解释成“现实被像素入侵”；即使画面热闹也失去原物的工艺魅力。若用户明确要求幻想奇观，则可尝试，但需为剧情服务。

### 许愿：「AI 特效想做得更有野心」

- 正确：在可用的真实 SDK、设备性能与平台政策内建立更好玩的操作、反馈和分享循环，同时明确实际技术约束。
- 错误：编造不存在的 API、把概念 UI 当平台真特效，或用“AI 觉醒系统”字眼掩盖贫弱的互动。

### 明确美学目标：「拍一部赛博朋克短片」

- 正确：可以且应该大胆采用未来都市、异化科技、霓虹与虚构装置，但要建立独特的世界逻辑、摄影语言和因果关系。反伪赛博不是全盘禁用科幻。
- 错误：为了避开伪赛博而拒绝用户明示的科幻题材，或者依然无差别复制俗套赛博模板。
