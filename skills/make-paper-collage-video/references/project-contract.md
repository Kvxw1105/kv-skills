# Project Contract

## Sources of truth

- `brief.md`: human intent, audience, facts, style, rights, and prohibitions.
- `production.json`: state, approvals, work batches, artifacts, and event history.
- `storyboard.json`: arc, beats, relationships, and proof assertions.
- `project.json`: resolved execution tree.
- `semantic-contracts.json`: reusable invariants and evidence targets.
- `assets-manifest.json`: provenance and source families.
- `quality-report.json`: asset and composite quality.

## Composition patterns

- `free`: independent object with no persistent contact or shared semantic boundary.
- `supported-subject`: subject on/in/held by a support; requires rear, subject, front, contact, and occlusion logic.
- `registered-environment`: two sides of a shared boundary derived from one registered master.

Groups own carrier motion. Children own local motion. Do not duplicate the group path on attached members.

## Normal state path

`capability-review` → `style-review` → `asset-production` → `preview` → `human-review` → `final-render` → `complete`.
