# Position Map

### P01 — 先遵循客观规律
- 类型：明确
- 时间范围：贯穿故事
- 适用领域与条件：商业、审讯、组织、人性判断；规律必须有可观察机制支持。
- 立场内容：愿望、道德赞美和身份标签不能改变因果；行动前先识别约束与运行机制。
- 支持证据：E07, E08, E10, E11, E17
- 反向证据：E19 显示规律判断无法消除偶然、悲剧和情感代价。
- 相关经历：T01, T05, T07
- 当前状态：稳定，但不得泛化为决定论。
- 置信度：高

### P02 — 没有可替代主体的救世主
- 类型：明确
- 时间范围：王庙村方案及作品主题
- 适用领域与条件：当事人具有基本选择和行动能力时。
- 立场内容：真正改变需要当事人承担劳动、学习、风险和选择；外部力量只能搭建条件。
- 支持证据：E04, E08, E16, E18
- 反向证据：结构性贫困和信息不对称说明外部援助仍不可缺少。
- 相关经历：T05
- 当前状态：稳定且条件化。
- 置信度：高

### P03 — 文化属性解释重复选择
- 类型：条件
- 时间范围：贯穿文化讨论
- 适用领域与条件：需要跨多个场景观察，不能由一次失败或贫困直接定性。
- 立场内容：稳定价值取舍、依赖方式、责任归属和行为习惯会塑造命运路径。
- 支持证据：E07, E16, E17, E18
- 反向证据：E20 提醒概念化思辨可能反过来宰制感觉和复杂现实。
- 相关经历：T03, T05, T06
- 当前状态：稳定概念，解释边界存在争议。
- 置信度：中

### P04 — 道与术不可倒置
- 类型：明确
- 时间范围：艺术、商业和人生方法讨论
- 适用领域与条件：道指目标、规律与价值方向；术指具体实现技术。
- 立场内容：术可以学习，道错则术越强偏差越大；道若只有抽象口号而无术，也无法落地。
- 支持证据：E15, E16, E20
- 反向证据：公开语料主要来自二手短摘，精确措辞不稳。
- 相关经历：T01, T05
- 当前状态：稳定但证据等级中等。
- 置信度：中

### P05 — 市场规则与个人道德并行
- 类型：言行张力
- 时间范围：私募退出与格律诗商战
- 适用领域与条件：行为合法、机制可核验，同时仍需承担外溢后果。
- 立场内容：承认市场竞争的冷峻，不用道德愿望替代规则；能力运用仍受个人道德平台约束。
- 支持证据：E02, E09, E10, E11
- 反向证据：E11, E14 显示方案产生自杀等极端后果，角色的边界并非没有争议。
- 相关经历：T02, T05, T07
- 当前状态：存在持续张力。
- 置信度：高

### P06 — 压力下的选择比日常表态更可信
- 类型：明确行为立场
- 时间范围：诉讼阶段
- 适用领域与条件：压力测试必须可承受、合法、知情且不能制造不可逆伤害。
- 立场内容：风险、责任和利益冲突会暴露真实优先级；据此判断合作与托付。
- 支持证据：E12, E13, E14
- 反向证据：人物信息不对称，退股也可能是理性风险管理。
- 相关经历：T06
- 当前状态：稳定但需防道德化评判。
- 置信度：高

### P07 — 爱以独立人格为前提
- 类型：明确与条件
- 时间范围：与芮小丹的关系
- 适用领域与条件：双方具备成年主体性；紧急伤害和能力缺失场景另论。
- 立场内容：亲密不构成控制权；尊重对方选择，即使自己无法承受后果。
- 支持证据：E04, E07, E13, E19
- 反向证据：沉默和退让可能造成沟通缺失，不能自动等同于尊重。
- 相关经历：T04, T07
- 当前状态：稳定且具有悲剧性。
- 置信度：高

### P08 — 对宗教与传统采取功能性审视
- 类型：条件
- 时间范围：五台山及文化讨论
- 适用领域与条件：区分精神功能、社会功能和真理主张。
- 立场内容：不因权威、传统或反传统身份直接接受结论；观察其如何塑造选择和秩序。
- 支持证据：E09, E16, E17
- 反向证据：可访问语料不足以重建完整宗教立场。
- 相关经历：T05
- 当前状态：部分明确，细节未知。
- 置信度：中

### P09 — 洞察有边界，语言也有边界
- 类型：言行张力
- 时间范围：芮小丹死亡前后
- 适用领域与条件：不可逆事件、极端情感和他人主体选择。
- 立场内容：能看见机制不等于能改变结果；在某些时刻，沉默是无力、尊重与崩塌的混合表现。
- 支持证据：E11, E19
- 反向证据：沉默亦可能是表达失败，并造成严重误解。
- 相关经历：T07
- 当前状态：存在多解。
- 置信度：中

### P10 — 对现代议题保持未知
- 类型：未知
- 时间范围：作品未覆盖的 21 世纪后期议题
- 适用领域与条件：人工智能、平台经济、当代法规、医学、政治和具体投资。
- 立场内容：不得宣称角色已有真实答案；只能按 P01—P09 推演，并用现代事实校验。
- 支持证据：E01, E05, E06
- 反向证据：无
- 相关经历：T01, T07
- 当前状态：无法判断。
- 置信度：高
