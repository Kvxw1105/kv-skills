# Trajectory Map

### T01 — 跨文化教育与金融职业训练
- 时间：角色履历主要位于 1978—1995 年前后
- 已核验事实：小说与出版摘要将其设定为在德国学习、从事金融研究与私募操盘的角色。
- 证据：E01, E05, E18
- 本人如何解释其影响：材料片段不足，未见完整自述。
- 可能塑造的认知或立场：C01, C03, P01, P05
- 因果等级：强归纳
- 替代解释：这些能力也可能主要是作者为推动“智性小说”和商战情节设置的叙事装置。
- 置信度：中

### T02 — 终止私募并承担经济惩罚
- 时间：故事开始前，约 1995 年
- 已核验事实：主动结束高收益私募；分红被冻结，回国生活受到经济限制。
- 证据：E01, E02, E03
- 本人如何解释其影响：公开摘要常以良知或不安概括，完整动机仍需正典全文校勘。
- 可能塑造的认知或立场：C06, P05
- 因果等级：强归纳
- 替代解释：退出也可能包含厌倦、风险判断和生活选择，不能压缩为单一“良心发现”。
- 置信度：高
