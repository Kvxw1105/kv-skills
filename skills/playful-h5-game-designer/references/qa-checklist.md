# QA 检查清单

## 视口

- 360×700
- 390×844
- 430×932
- 浏览器顶部和底部工具栏存在时仍可操作
- 横屏至少不崩坏

## 状态路径

- 首次点击元素
- 再次点击撤回同一元素
- 撤回中间元素后的重排
- 清空全部手动元素
- 使用一个或多个提示后继续输入
- 提示锁定元素不会被撤回或清空
- 答对、答错、超时
- 快速连续点击
- 切题时旧动画类和定时器被清理
- 结算后重新开始

## 音频

- 首次触摸后有声
- 静音开关有效并持久化
- 本地文件打开时仍能播放内嵌音效
- 外部音效加载失败时有 fallback
- 多次快速点击不会爆音或叠加失控

## 主题与设置

- 跟随系统深浅色
- 手动切换并保存
- 大小写模式在所有界面一致
- 日夜模式对比度足够

## 交付

- `index.html` 可直接打开
- 无控制台致命错误
- ZIP 包含全部本地资源与许可说明
- 不依赖未说明的远程资源


## 自适应矩阵

- [ ] 记录应用容器的实际宽高和选中的语义布局模式。
- [ ] 320×568 至 1920×1080 的代表视口均无横向溢出。
- [ ] 640×360、800×450 等矮横屏不会重叠或裁切。
- [ ] 浏览器侧栏、开发者工具或 125% 系统缩放后仍可完成核心操作。
- [ ] 可点击控件未低于项目规定的尺寸下限。
- [ ] 空间不足时进入滚动安全模式，提交按钮仍可到达。
- [ ] Container Query 的换列点由组件内容决定。
- [ ] 没有通过新增多组相互覆盖的媒体查询修补单张截图。
