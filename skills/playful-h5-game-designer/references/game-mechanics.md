# 轻量小游戏机制

## 核心循环

打开即懂 → 立即操作 → 频繁小反馈 → 一局有明确终点 → 结算可比较 → 次日有新内容。

## 难度

- 先通过题目长度、词频、干扰强度和时间限制分层。
- 默认不要只用统一难度。
- 每日公开挑战可统一题目；练习模式可个性化。
- 提示使用率是难度探针：大量用户在同一题使用提示，说明题目可能放错层级。

## 提示

将强提示和渐进提示拆开：

- 语义提示：强提示，次数少，独立按钮。
- 字母提示：按答案顺序逐个揭示，并固定到正确槽位。
- 提示字母与用户输入分开存储。
- 同一题连续提示必须产生新的信息。

## 题量

题量本身是品牌符号和节奏参数。12 题适合 3×4 进度矩阵、2–4 分钟一局，也有较强记忆点。修改题量时同步更新题号、进度、结算、分享与题库。

## 分享与留存

分享内容优先包含：得分、击败比例、最快一题、连续天数与挑战入口。不要在首版加入复杂人格系统，除非标签由真实行为数据触发。
