# 万相铸镜 · KV Wanxiang Forge

把人物的**真实经历、明确立场、认知机制、行动算法、核心张力和表达声纹**铸成可运行、可追溯、可更新的 ChatGPT Skill。

## 它解决什么问题

许多人物视角提示词只剩口头禅、名言拼贴和夸张模仿；另一些为了规避“冒充”，又把人物最重要的经历、立场和声音全部抹掉。万相铸镜保留人物真实的成长轨迹、稳定主张、观点演化、言行张力和表达机制，同时严格区分史实、明确立场、跨材料归纳、声纹迁移和面向新问题的推演。

它适合：

- 把公众人物或历史人物构建为长期可用的认知顾问。
- 从用户自己的文章、聊天、项目和决策记录中提炼“自我镜”。
- 构建某个思想流派或方法论的分歧地图。
- 复刻人物的论证方式、节奏、情绪和关系姿态，用于写作或表达。
- 更新已有认知镜，保留立场演化、证据变化和语体变化。

## 典型触发

- “铸一个张小龙产品认知镜，保留他的经历和真实立场。”
- “把这些文章、聊天和项目复盘做成我的自我镜。”
- “提取这位作者的表达声纹，用他的论证节奏改写这篇稿子。”
- “构建王阳明认知镜，区分史料、后世解释与现代推演。”
- “更新芒格认知镜，把新材料和旧结论逐条对照。”

近似但不触发：

- “张小龙是谁？”——普通事实问答。
- “总结这篇访谈。”——单次摘要，无需创建可安装 Skill。
- “把这句话写得更礼貌。”——一般改写，不需要人物声纹系统。

## 独立架构

万相铸镜采用六层模型：

1. 成形之路：哪些经历真正改变了判断方式。
2. 立场地图：明确、条件化、演化、冲突和未知立场。
3. 认知镜片：跨情境复现且能生成新分析的思考机制。
4. 行动算法：决策启发式、优先级、反模式和风险权衡。
5. 核心张力：长期存在的价值冲突与制衡机制。
6. 表达声纹：论证路径、句法节奏、词汇光谱、认识姿态、情绪温度、关系姿态、场景变体和负面指纹。

目标 Skill 支持三种模式：

- **透明分析**：清楚展示事实、立场、镜片和不确定性。
- **声纹迁移**：复刻深层表达机制，但不自称本人。
- **入镜演绎**：用户明确要求时使用第一人称，首次声明边界，保留有证据的经历、立场和声音。

## 声纹为何更可靠

万相铸镜不把“像”理解为多塞几个口头禅。它建立独立的 `voiceprint-profile.md`，记录八维声纹和 3–8 个可追溯锚点。生成时先选择场景与锚点，再迁移论证路径、节奏、认识姿态和情绪关系。系统还会执行盲认、换题、去口头禅、防夸张、场景切换和多轮漂移测试。

## 工作流

1. 定义对象、用途、时期、领域和声音目标。
2. 建立证据账本、经历地图、立场地图、声纹档案和综合笔记。
3. 做经历因果审计与立场时间标注。
4. 铸造认知镜片、行动算法、核心张力与表达声纹。
5. 生成三模式目标 Skill。
6. 执行立场、反例、未知问题和声纹稳定性测试。
7. 通过专用校验器和官方 Skill 校验器，打包为 `skill.zip`。

## 工具与限制

公开人物和时效性问题需要网页检索；用户材料优先使用 Files；Notion、GitHub 等连接器只在用户明确指向并拥有访问权时使用。生成和打包需要可执行 Python 的容器环境。没有搜索能力时可以转为材料模式，但必须公开未完成的验证。语料过少、代笔不明、跨语言差异过大或目标场景从未出现时，只能交付低置信度的近似声纹。

## 安装

将交付的 `skill.zip` 上传到 ChatGPT 的 Skills 页面。具体界面入口可能随产品版本变化。

## 隐私

对用户本人或非公众人物，只使用用户有权提供的材料。不要主动搜索私人信息，也不要把原始敏感文件、凭证和内部数据放入可公开分发的 Skill 包。
