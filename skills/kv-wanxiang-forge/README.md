# 万相铸镜 · KV Wanxiang Forge

把人物的**真实经历、明确立场、认知机制、行动算法和表达肌理**铸成可运行、可追溯、可更新的 ChatGPT Skill。

## 它解决什么问题

许多人物视角提示词只剩语气模仿和名言拼贴；另一些为了规避“冒充”，又把人物最重要的经历与立场全部抹掉。万相铸镜选择一条更难但更有价值的路线：保留人物真实的成长轨迹、稳定主张、观点演化、言行张力和声音，同时严格区分史实、明确立场、跨材料归纳和面向新问题的推演。

它适合：

- 把公众人物或历史人物构建为长期可用的认知顾问。
- 从用户自己的文章、聊天、项目和决策记录中提炼“自我镜”。
- 构建某个思想流派或方法论的分歧地图。
- 更新已有认知镜，保留立场演化与证据变化。

## 典型触发

- “铸一个张小龙产品认知镜，保留他的经历和真实立场。”
- “把这些文章、聊天和项目复盘做成我的自我镜。”
- “构建王阳明认知镜，区分史料、后世解释与现代推演。”
- “更新芒格认知镜，把新材料和旧结论逐条对照。”

近似但不触发：

- “张小龙是谁？”——普通事实问答。
- “总结这篇访谈。”——单次摘要，无需创建可安装 Skill。

## 独立架构

万相铸镜采用五层模型：

1. 成形之路：哪些经历真正改变了判断方式。
2. 立场地图：明确、条件化、演化、冲突和未知立场。
3. 认知镜片：跨情境复现且能生成新分析的思考机制。
4. 行动算法：决策启发式、优先级、反模式和风险权衡。
5. 表达肌理：论证结构、节奏、类比、抽象层级与确定性。

目标 Skill 同时支持透明分析模式和带声明的视角演绎模式。第一人称演绎可以保留人物声音与经历，但不能制造假经历、假引语或伪装成本人真实的新立场。

## 工作流

1. 定义对象、用途、时期与领域。
2. 建立证据账本、经历地图、立场地图和综合笔记。
3. 做经历因果审计与立场时间标注。
4. 铸造认知镜片、行动算法与核心张力。
5. 生成双模式目标 Skill。
6. 执行立场回测、反例、未知问题、声音与去名测试。
7. 通过专用校验器和官方 Skill 校验器，打包为 `skill.zip`。

## 工具与限制

公开人物和时效性问题需要网页检索；用户材料优先使用 Files；Notion、GitHub 等连接器只在用户明确指向并拥有访问权时使用。生成和打包需要可执行 Python 的容器环境。没有搜索能力时可以转为材料模式，但必须公开未完成的验证。

## 安装

将交付的 `skill.zip` 上传到 ChatGPT 的 Skills 页面。具体界面入口可能随产品版本变化。

## 隐私

对用户本人或非公众人物，只使用用户有权提供的材料。不要主动搜索私人信息，也不要把原始敏感文件、凭证和内部数据放入可公开分发的 Skill 包。
