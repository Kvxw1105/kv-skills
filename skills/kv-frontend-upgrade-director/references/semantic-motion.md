# 语义动效与状态空间化

## 核心公式

`用户动作 → 业务状态 → 视觉对象变化 → 反馈 → 可编辑结果`

动画应解释系统发生了什么，而不是向用户证明开发者会动画。

## 状态分离

至少区分：业务内容、用户输入、异步任务、动画临时状态、成功/失败、设置、持久化。禁止用一个布尔值控制复杂流程。

## 时间尺度

- 高频操作反馈：80–180ms；
- 组件状态变化：180–320ms；
- 页面/共享元素过渡：320–700ms；
- 结算或品牌演出：0.7–2.4s，可跳过、可降级。

## 可复用语义

- 输入 → 聚合或吸入；
- 分析 → 分裂、标注、分轨；
- 生成 → 生长、结晶、装配；
- 匹配 → 对齐、吸附、建立连接；
- 排队 → 轨道、层级和前后关系；
- 输出 → 压平、封装、落入工作区；
- 撤回 → 沿原路径返回；
- 失败 → 停止、保留上下文、提供恢复。

## 连续性

元素必须有来源和去向。DOM、SVG、Canvas 和 WebGL 可以通过临时视觉层接力，制造同一对象跨媒介转化的知觉连续性。

## 竞态

异步期间锁定重复提交或使用稳定任务 ID。动画结束后清理临时节点、class、定时器和资源；不得让旧回调删除新状态。
