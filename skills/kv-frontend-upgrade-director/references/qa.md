# 前端质量验收矩阵

## 证据状态

- `observed`：直接可见；
- `reproduced`：按步骤稳定复现；
- `inferred`：根据代码或风险推断；
- `existing`：改造前已存在；
- `regression`：本轮引入；
- `fixed_verified`：修复并复测通过。

## 核心路径

至少测试：进入 → 核心操作 → 加载 → 成功结果；一条失败/恢复路径；重复提交；空状态；权限或资源失败。

## 尺寸

代表视口：320×568、390×844、430×932、640×360、768×1024、1024×768、1366×768、1700×864、1920×1080。检查 80%、100%、125%、150% 缩放和矮窗口。

## 视觉与交互

- 3 秒内知道页面作用和主操作；
- 主焦点明确，背景动效不降低阅读；
- Button/Input/Select/Table/Modal/Toast 状态完整；
- hover 不承载唯一信息；
- focus-visible 清楚；
- loading 防止重复提交；
- disabled 仍可识别；
- 危险操作有确认与恢复。

## 响应式与性能

- `scrollWidth <= clientWidth`；
- 关键按钮可到达，触控目标接近或不低于 44px；
- 固定层不覆盖正文；
- 手机不是桌面整体缩小；
- 动画不造成布局跳动；
- WebGL/Canvas 有低性能和失败降级；
- 控制台、网络、内存和资源释放无明显问题。

## 诚实交付

分列：已测试通过、失败后已修复、无法测试、仍有风险。没有真实运行浏览器时，不得写“全面适配通过”。
