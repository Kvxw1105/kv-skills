# 响应式、性能与降级契约

## 空间预算

开发前定义：最小可用宽高、理想宽高、最大内容宽度、核心区域最低尺寸、触控目标下限、滚动方式和隐藏顺序。

宽度决定区域关系，高度决定密度和安全滚动。矮屏不能套用更高的手机布局。

## 布局技术

- 页面骨架使用 Grid/Flex；
- 组件使用 `minmax()`、`clamp()`、`auto-fit`、Container Query；
- Grid/Flex 子项设置 `min-width:0`，必要时 `min-height:0`；
- 使用 `100dvh` 和 safe-area；
- 绝对定位不承担主布局；
- 不整体 `transform:scale()` 缩小应用。

## 降级顺序

减少外边距 → 减少装饰间距 → 缩小非核心文字 → 组件换行 → 区域重排 → 隐藏说明/装饰 → 启用安全滚动。达到可读与触控下限后禁止继续缩小。

## 性能预算

- 限制初始 JS、字体、图片和纹理；
- 动画优先 transform/opacity；
- 控制 DPR、粒子和透明层；
- 懒加载非首屏创意层；
- 页面隐藏时暂停高频循环；
- 监听器、RAF、Observer 和 WebGL 资源必须清理。

## 创意层降级

完整 WebGL → 简化 WebGL → Canvas/SVG → 静态视觉。任何级别下核心功能、文本、按钮和结果路径必须可用。
