# 核心哲学

## 1. 前端不是皮肤

前端升级同时处理：产品理解速度、任务完成效率、状态可见性、品牌识别、操作反馈、响应式、性能、可访问性与恢复能力。只换色、圆角和阴影不构成升级。

## 2. 三层体验结构

- **功能实体层**：信息、表单、列表、编辑、结果、错误恢复。必须稳定。
- **品牌表达层**：字体、色彩、材质、构图、语气。形成识别。
- **创意增强层**：动效、Canvas、WebGL、声音、空间叙事。失败时可降级。

创意层不得成为理解和操作核心功能的唯一途径。

## 3. 视觉权威

一个页面只允许一个视觉统治者。它可以是真实产品界面、核心对象、空间场景、关键数据或内容封面。其他元素必须在亮度、尺寸、密度和运动上服从它。

## 4. 技术选择

选择最轻、能完整表达因果的技术：

- 静态层级问题先修排版与 Token；
- 状态反馈优先 CSS/SVG；
- 大量轻量粒子可用 Canvas；
- 真正的空间、材质、镜头与实时数据才用 WebGL；
- 复杂产品优先保持 DOM 可读与可操作。

## 5. 停止条件

当核心路径、共享组件、代表页面、移动端、主题、错误恢复和性能目标均达到验收线时停止。不要为了“再高级一点”持续加入特效和依赖，制造回归风险。
