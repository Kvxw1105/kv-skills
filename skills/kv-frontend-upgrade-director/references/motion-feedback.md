# 动效、声音与操作手感

## 反馈矩阵

每个高频动作定义：视觉变化、声音、触觉、持续时间、可否叠加、失败降级。

- 点击：轻压缩与回弹，低延迟；
- 选择：颜色、位置或轮廓变化，可追踪；
- 提交：锁定、防重复、进度可见；
- 撤回：沿来源路径返回；
- 成功：聚合、上扬或释放，结果清楚；
- 错误：短、低、克制，保留恢复路径；
- 结算：分层出现，可截图，可跳过。

## 缓动

高频操作避免大弹簧和长尾。页面级过渡使用少量统一曲线。连续跟随采用插值或阻尼，不直接赋值造成硬跳。

## Web Audio

首次用户手势后创建或恢复 AudioContext。短音使用快速起音与指数衰减，限制并发和音量。声音默认可关闭，不能承担唯一反馈。外部素材记录来源和许可。

## 触觉

触觉只作为增强层。iOS 浏览器可能不支持振动；不得依赖它表达成功、失败或危险操作。

## 无障碍

支持 `prefers-reduced-motion`。关闭动画后仍保留状态、顺序和结果，不因减少动态而隐藏内容。
