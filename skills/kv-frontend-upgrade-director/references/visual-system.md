# 前端视觉系统

## 视觉命题

先定义：情绪 + 材质 + 核心形状 + 动态特征 + 克制原则。

例如：
低照度东方神性 + 墨纸材质 + 残缺星盘 + 缓慢蓄力 + 少装饰。

## 设计规则

- 一个主焦点。
- 两级强调色以内。
- 色彩、字号、间距、边框、动画时间统一使用 Token。
- 高级来自秩序，不来自装饰数量。

## 对标转译

学习：
- Linear 的产品叙事。
- Lusion 的 WebGL 空间。
- Active Theory 的实时体验。
- Stripe Press 的内容结构。

只迁移底层规律，不复制外观。

## 反模板

避免：
- 紫蓝渐变 AI 风。
- 满屏玻璃卡片。
- 无意义粒子宇宙。
- 所有元素争夺注意力。
