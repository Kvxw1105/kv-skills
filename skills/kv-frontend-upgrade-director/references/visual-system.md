## 1. 视觉命题

在写 CSS 前，用一句话锁定：

`情绪 + 材质/媒介 + 核心形状 + 动态特征 + 克制原则`

抽象词必须转成参数：

- 高级 → 低色数、精确留白、稳定层级、克制阴影；
- 炫酷 → 一个主动态、强暗部、局部高亮、有限速度；
- 科技 → 状态、数据关系和空间秩序，不等于霓虹；
- 东方 → 留白、材质、结构和节奏，不等于装饰堆砌。

## 2. Design Tokens

至少定义：背景/表面/浮层、主次文字、强调/成功/危险、弱强边框、空间标尺、字体角色、圆角职责、阴影职责、层级、动画时长和缓动。

Token 名必须语义化，禁止组件内散落大量无关魔法数字。深浅主题分别校准，不做机械反色。

## 3. 信息层级

通过亮度、尺寸、位置、密度和运动共同建立层级。不要让标题、图标、按钮和卡片全部高亮。辅助信息主动退后，但保持可读。

## 4. 材质与光

每个项目只选一套主要材质逻辑，例如纸张、金属、玻璃、织物、墨、工业面板。光效有明确光源和作用对象；辉光只强化焦点、状态或深度。

## 5. 反 AI 味

默认避免：

- 紫蓝渐变科技背景；
- 满屏玻璃卡片；
- 同尺寸圆角矩形铺满页面；
- 无意义粒子和网格；
- 假数据、假产品截图和装饰性 KPI；
- 三套方案只换色；
- 用 Inter/Roboto 作为所有项目的默认展示字体；
- 用 `overflow:hidden` 隐藏布局错误。

正向方法：从真实产品任务、内容、品牌资产和操作状态推导视觉。

## 6. 验收

- 缩成 25% 时主焦点是否明确；
- 黑白查看时层级是否仍成立；
- 关闭动态层后页面是否仍有设计；
- 每个装饰是否服务情绪、信息或操作；
- 是否一眼像通用 AI 模板；
- 手机端是否保留同一视觉语言但重新组织布局。
