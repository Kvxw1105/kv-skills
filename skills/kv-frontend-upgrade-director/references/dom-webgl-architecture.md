# DOM、Canvas 与 WebGL 分层架构

## 职责

- DOM：语义内容、表单、按钮、列表、编辑、键盘和无障碍；
- CSS/SVG：微交互、布局过渡、图标和轻量可视化；
- Canvas 2D：氛围、波形、粒子和低成本动态图形；
- WebGL/Three.js：空间、镜头、材质、实例化对象和实时数据；
- 覆盖层：颗粒、暗角、扫描线、Toast、临时跨媒介动画。

## 同步方式

业务状态为唯一事实源。DOM 和 WebGL 订阅同一状态，不互相猜测。滚动、鼠标和时间轴只是输入，不能直接成为业务状态。

## 指针策略

背景 Canvas 默认 `pointer-events:none`。需要空间交互时，只在明确区域启用 Raycaster，并保留等价 DOM 操作路径。

## 失败降级

远程库、模型、纹理或 WebGL 初始化失败时：

1. 保留 DOM 核心内容和操作；
2. 切换 CSS/SVG/Canvas 静态或轻量版本；
3. 提示降级状态但不阻塞任务；
4. 记录错误，避免循环重试。

## 禁止

不要把可读正文、表格、表单和关键按钮全部画进 Canvas。不要让 3D 场景承担唯一导航或唯一状态信息。
