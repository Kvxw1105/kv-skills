# 热插拔提示词模块

模块由 `scripts/compile_prompt.py` 组合。每个文件应可独立追加到现有开发提示词中。

- `00-protection.md`：所有已有项目默认前置；
- `01`–`20`：来自 v1 母稿的专项模块；
- `90-output-schema.md`：统一 Agent 输出；
- `91-round-plan.md`：弱模型分轮执行。

推荐 profile：

- `existing-project`：非破坏整体升级；
- `wow`：提升第一眼视觉事件与空间体验；
- `workspace`：编辑器/工具/后台；
- `h5`：手机轻应用；
- `brand`：官网、个人 IP、内容站；
- `patch`：只修细节和验收；
- `full`：完整母体，适合强 Agent 和复杂项目。
