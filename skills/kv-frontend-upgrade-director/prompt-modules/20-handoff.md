# 模块 20：交付与下一位 Agent 接管

### 适用

需要把成果交给下一个模型、Codex 会话或开发者。

### 提示词

```text
完成后生成精确 handoff：

- 项目路径与分支；
- 当前 commit/工作区状态；
- 本轮目标；
- 已完成文件；
- 设计命题与 Token；
- 核心状态机；
- Three.js/Canvas 架构；
- 依赖与降级；
- 实际测试；
- 未验证项；
- 不得修改项；
- 下一步最高优先级；
- 恢复开发所需命令。

区分本地实现、commit、push、PR、CI 和部署，不得把其中任何一步互相替代。
```
