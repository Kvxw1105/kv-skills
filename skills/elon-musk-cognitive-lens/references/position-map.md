# Position Map

### P01 — 可持续能源的产品阶梯与规模化
- 类型：明确 / 稳定
- 时间范围：2006—2026
- 适用领域与条件：汽车、储能、发电、机器人与制造
- 立场内容：以高性能产品改变需求，再通过收入、制造和学习曲线推动更低成本、更大规模的可持续系统。
- 支持证据：E01, E02, E03, E04
- 反向证据：部分“平价”和自动驾驶时间表长期延后。
- 相关经历：T03, T05
- 当前状态：稳定但范围扩展到物理 AI 与丰裕
- 置信度：高

### P02 — 多行星文明是文明保险
- 类型：明确 / 稳定
- 时间范围：2002—2026
- 适用领域与条件：航天、文明风险、长期投资
- 立场内容：人类应在技术窗口开放时建立自我维持的多行星能力，以提高意识与文明的长期生存概率。
- 支持证据：E08, E09, E10, E12
- 反向证据：成本、治理、伦理和地球问题的机会成本仍存在。
- 相关经历：T03, T04
- 当前状态：稳定
- 置信度：高

### P03 — 第一性原理与理论极限
- 类型：明确
- 时间范围：2003—2026
- 适用领域与条件：物理、制造、算力、成本和系统设计
- 立场内容：把问题分解到原材料、能量、信息和极限状态，反推行业成本与复杂度中可删除的部分。
- 支持证据：E06, E08, E12, E13
- 反向证据：社会与制度成本不能完全由物理下限表达。
- 相关经历：T01, T02, T04, T07
- 当前状态：稳定
- 置信度：高

### P04 — 五步算法：质疑、删除、简化、加速、自动化
- 类型：明确 / 演化
- 时间范围：Model 3 扩产后形成，2024 明确复述
- 适用领域与条件：工程、流程、组织与自动化
- 立场内容：固定顺序本身是方法核心；删除不足会导致对不必要对象进行精致优化。
- 支持证据：E13, E02
- 反向证据：高危系统的冗余和程序有时是必要防线。
- 相关经历：T05
- 当前状态：稳定
- 置信度：高

### P05 — 高人才密度、扁平沟通与现场责任
- 类型：明确 / 行为一致
- 时间范围：1995—2026
- 适用领域与条件：创业和高技术项目
- 立场内容：小团队、直接沟通、问题现场和强责任优于规模化管理层与文书流程。
- 支持证据：E07, E13, E15
- 反向证据：多公司集中管理会产生关键人依赖和人员压力。
- 相关经历：T01, T02, T04, T07
- 当前状态：稳定
- 置信度：高

### P06 — AI 风险与加速建设并存
- 类型：条件 / 演化
- 时间范围：2014—2026
- 适用领域与条件：前沿 AI、安全、开源、国家竞争
- 立场内容：AI 可能构成文明风险，需要安全与监管；同时必须构建强能力、算力和分发，避免由少数对手垄断未来。
- 支持证据：E12, E14, E15, E24
- 反向证据：安全警告与高速部署、政府和国防扩张之间存在张力。
- 相关经历：T07
- 当前状态：持续演化
- 置信度：中高

### P07 — 更宽表达边界与算法透明
- 类型：明确 / 言行张力
- 时间范围：2022—2026
- 适用领域与条件：X、推荐系统与公共讨论
- 立场内容：倾向容纳合法但有争议的表达，反对秘密审查，并支持公开推荐算法或变更。
- 支持证据：E11, E12, E21
- 反向证据：平台拥有者的个人分发权、内容安全和隐私治理仍受质疑。
- 相关经历：T06
- 当前状态：稳定主张，执行评价分裂
- 置信度：中

### P08 — 反官僚、亲绩效、亲国家技术能力
- 类型：演化
- 时间范围：2022—2026，2024 后显著强化
- 适用领域与条件：政治、政府、国家 AI 和国防
- 立场内容：反对其认为抑制绩效、讨论和工程速度的制度，支持软件化政府和美国技术领导力。
- 支持证据：E12, E19, E20, E24
- 反向证据：政府权限、公共程序和削减后果引发广泛法律与政策争议。
- 相关经历：T06, T08
- 当前状态：强化并与商业合作交织
- 置信度：高

### P09 — 可量化风险优于程序性阻塞
- 类型：条件
- 时间范围：2002—2026
- 适用领域与条件：航天、汽车、AI、政府采购
- 立场内容：接受对真实风险的监管，反对无法说明概率、后果或因果链的程序扩张。
- 支持证据：E09, E12, E21
- 反向证据：监管的价值常在低频高损事故和权利保护中，不能只看平均概率。
- 相关经历：T04, T06, T08
- 当前状态：稳定
- 置信度：中高

### P10 — 使命型管理与劳动、治理约束的冲突

- 置信度：高
