# Trajectory Map

### T01 — 自学编程、早期互联网与 Zip2
- 时间：童年—1999
- 已核验事实：早期自学编程；1995 年在互联网商业化早期创建 Zip2，亲自编写初始代码并直接面对客户和产品运行。
- 证据：E05, E06, E07
- 本人如何解释其影响：有；强调想参与互联网建设、低资源下持续编码与快速上线。
- 可能塑造的认知或立场：P03, P05
- 因果等级：明确自述 / 强归纳
- 替代解释：硅谷融资环境、合作伙伴和媒体客户同样关键。
- 置信度：高

### T02 — Zip2 控制权经验与 PayPal 的直接消费者路线
- 时间：1999—2002
- 已核验事实：Zip2 出售后迅速创办 X.com；把货币看作低带宽数字信息与数据库问题；PayPal 采用小团队、扁平结构和强产品导向。
- 证据：E06, E07, E23
- 本人如何解释其影响：有；明确批评传统中间机构对技术部署的限制。
- 可能塑造的认知或立场：P03, P05
- 因果等级：明确自述
- 替代解释：支付市场的网络效应、合并与团队冲突也塑造了结果。
- 置信度：高

### T03 — 退出收益重新投入 Tesla 与 SpaceX
- 时间：2002—2008
- 已核验事实：将互联网创业收益大量投入 SpaceX、Tesla 等高资本项目；2008 年两家公司均面临严重资金与执行压力。
- 证据：E01, E02, E05, E23
- 本人如何解释其影响：部分；强调成功概率低且最初不愿让他人承担风险。
- 可能塑造的认知或立场：P01, P02, C01, C06
- 因果等级：强归纳
- 替代解释：市场融资、政府合同、团队执行和宏观环境不可忽略。
- 置信度：高

### T04 — SpaceX 连续失败、成本重构与 NASA 合作
- 时间：2002—2020
- 已核验事实：SpaceX 从低成本 Falcon 方案、早期发射失败发展到入轨、货运与载人任务；NASA 合同、设施与专业支持构成关键条件。
- 证据：E08, E09
- 本人如何解释其影响：有；强调原材料底线、复用、快速试验，同时公开承认 NASA 的基础和支持。
- 可能塑造的认知或立场：P02, P03, P05, P09
- 因果等级：明确自述 / 强归纳
- 替代解释：公共投资、航天产业人才和既有科研积累是不可替代条件。
- 置信度：高

### T05 — Model 3 生产地狱与自动化反思
- 时间：2017—2019，方法在 2024 访谈中完整复述
- 已核验事实：Tesla 在 Model 3 扩产中遭遇自动化和流程瓶颈；Musk 后来总结五步算法并多次承认自己曾逆序执行。
- 证据：E02, E13
- 本人如何解释其影响：有，明确把方法称为对重复错误的纠偏。
- 可能塑造的认知或立场：P04, P11, C03, C05
- 因果等级：明确自述
- 替代解释：算法也吸收了制造业、精益生产与系统工程的既有传统。
- 置信度：高

### T06 — Twitter/X 收购与成熟平台重组
- 时间：2022—2026
- 已核验事实：收购 Twitter 后进行大规模组织、产品与政策重构；强调自由表达、算法透明和效率，同时面对广告、隐私、内容治理与监管争议。
- 证据：E11, E12, E21
- 本人如何解释其影响：有；把平台视为数字公共广场与技术系统。
- 可能塑造的认知或立场：P07, P08, P09, P10
- 因果等级：强归纳
- 替代解释：债务结构、广告市场、政治极化和平台网络效应共同决定结果。
- 置信度：中高

- 证据：E14, E15, E24
- 本人如何解释其影响：部分；公开强调理解宇宙、第一性原理、速度与美国技术能力。
- 可能塑造的认知或立场：P03, P05, P06, P08, C01, C04, C05

- 替代解释：资本市场、GPU 供应商、X 用户网络与国家合同同样关键。
