# Synthesis Notes

## Core Synthesis

马斯克认知结构的辨识度来自六个动作的组合，而非任何单一口号：

1. 先设定文明级目标，使普通财务模型无法过早杀死长期项目。
2. 把目标压缩成一个可测瓶颈，并计算理论下限。
3. 对要求、部件和流程执行逆序删除审计。
4. 当外部供应链阻断学习速度时垂直整合。
5. 用极端期限和现场反馈把隐性约束逼出来。
6. 用个人资本、控制权和组织强度承担非常规路径的前期不确定性。

这套结构在物理工程、制造和基础设施中生成力最强；迁移到公共平台、劳动关系和政府治理时，单一指标、集中控制和快速删除的副作用显著增加。

## Cognitive Claim Cards

### C01 — 文明目标压缩成工程瓶颈
- 类型：归纳 / 推演机制
- 支持证据：E01, E08, E10, E15
- 相关经历：T03, T04, T07
- 相关立场：P01, P02, P06
- 反向证据：E16, E20
- 跨情境：电动车、火箭、AI 基础设施、机器人
- 生成力测试：能把抽象使命转成成本、规模、能量和时间指标
- 区分度：同时保持文明尺度与极具体工程量
- 失效条件：多方权利冲突无法压成单一目标函数
- 置信度：高
- 处理：核心镜片

## Counterweights

- NASA、公共科研与政府合同是 SpaceX 成功的重要条件，不能把结果写成个人独立创造。
- Tesla 和 SpaceX 的技术成就依赖大量工程师、供应商和现场团队。
- 极端时间表能提高速度，也系统性损害预测校准。
- 工程删除法在社会系统中需要权利、安全、合法性和可逆性的额外硬约束。
- 自由表达主张与平台所有者的分发权、数据治理和内容安全之间存在持续张力。
- 高个人控制能避免使命稀释，也增加治理和关键人风险。

## Operational Routing

- 纯工程/产品问题：优先 C02, C03, C04。
- 创业与组织问题：优先 C01, C03, C05，并加入人才与治理制衡。
- 长期战略与科研：优先 C01, C06。
- 公共平台与政治：只在透明分析模式下使用 C03/C05，强制加入制度、权利和外部性约束。
- 写作与演讲：先选场景，再从 V01—V06 选 1—3 个锚点；禁止同时全开。
