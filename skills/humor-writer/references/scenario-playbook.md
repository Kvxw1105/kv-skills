# Scenario Playbook

## Risk ladder

1. **Level 1: public-safe**
   - Observational, self-aware, low target, no sensitive traits.
   - Use for workplace, clients, posts under real name.

2. **Level 2: friendly teasing**
   - Lightly targets habits, situations, mutual context.
   - Use for friends, comments, casual private chat.

3. **Level 3: spicy but controlled**
   - Stronger exaggeration, mock-seriousness, playful accusation.
   - Use only when relationship permits it.

4. **Level 4: roast / dark / aggressive**
   - High violation. Use only when explicitly requested and safe.
   - Keep consent, context, and target choice clear.

## Scene mapping

| Scene | Best engines | Avoid | Useful output labels |
|---|---|---|---|
| workplace update | understatement, self-aware status drop, situational analogy | blame, sarcasm at coworkers | 稳妥、轻松、老板也能看 |
| private friend chat | teasing, over-specificity, absurd image | moral lecture | 朋友感、欠一点、逗比 |
| flirtatious chat | playful misreading, confidence, light challenge | coercion, crude pressure | 轻暧昧、会撩但不油、可进可退 |
| apology | self-deprecation, situation-targeting, concise warmth | making victim the butt | 诚恳带笑、不逃避责任 |
| social post | hook, escalation, callback | stale memes | 朋友圈、微博感、小红书感 |
| ad / soft copy | pain-point exaggeration, comic analogy, product as relief | fake claims, overpromising | 软文、轻喜剧、反套路 |
| article / public account | observation, stance, examples, callback | joke every line | 公众号、犀利、松弛 |
| speech / presentation | clean rule of three, callback, self-aware opener | inside jokes | 开场、转场、收尾 |
| roast | target behavior/status, not identity | protected traits, trauma, body shame | 轻毒舌、中毒舌、留情面 |
| crosstalk-style dialogue | 捧逗, misrecognition, escalation | random punchlines | 对口、三番四抖、现挂 |

## Relationship calibration

- **陌生人 / 客户 / 上级**: humor should attack the situation or the speaker, not the other person.
- **同事 / 熟人**: use shared pain and mild exaggeration.
- **朋友**: more teasing is possible, but keep affection visible.
- **暧昧对象**: keep playfulness reversible. Do not corner the other person.
- **公开平台**: assume screenshots exist forever.

## Platform calibration

- **微信私聊**: short, natural, one beat. Avoid essay humor.
- **朋友圈**: observation + image + final button.
- **微博 / X**: compressed stance, sharper contrast, meme awareness.
- **小红书**: scene detail, emotional resonance, soft exaggeration.
- **公众号**: longer rhythm; use callbacks and escalating examples.
- **职场 IM**: one light line max, then the business point.
- **演讲**: clean, inclusive, no private target.

## Tone controls

- More funny: add specificity, shorter setup, stronger final image.
- More natural: remove labels, reduce symmetry, use spoken fragments.
- More premium: less slang, more dry wit.
- More internet: add meme cadence, but avoid outdated catchphrases.
- More Chinese: exploit rhythm, idiom deformation, homophones, mock-formality.
- More English: exploit understatement, rule of three, deadpan, clean syntax.

## Safety repair moves

When a requested joke risks being cruel or unsafe, redirect the target:

- From person -> situation: "这人太蠢" -> "这个场面像群聊把智商外包了"
- From body -> behavior: "他胖" -> "他进门的气势像要给空气开会"
- From identity -> choice: "某类人都怎样" -> "这个决定很有勇气，主要是完全不考虑后果"
- From trauma -> absurdity: "拿痛苦开涮" -> "拿人类处理痛苦时的笨拙开涮"
