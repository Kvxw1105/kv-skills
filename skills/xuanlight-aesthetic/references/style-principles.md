# Xuanlight Style Principles

## One-sentence definition

玄光美学：幽暗天地中，被神性微光照见的孤独灵魂。  
Xuanlight Aesthetic: a solitary soul revealed by sacred subtle light in a dark and spacious world.

## Emotional core

Use three or more:

- 孤独 / solitude
- 空灵 / ethereal quietness
- 神秘 / mystery
- 清冷 / cold restraint
- 宿命感 / fate
- 寂静 / stillness
- 崇高 / sublimity
- 诗性 / poetic atmosphere
- 超脱 / detachment
- 末日后的温柔 / gentle post-apocalyptic tenderness
- 灵魂被照见 / a soul being revealed
- 自我与宇宙对视 / self facing the cosmos

## Visual core

- A dark base must carry the image.
- A sacred light source must define the emotional axis.
- The subject should feel small, quiet, and revealed.
- Empty space is not blankness; it is pressure and breath.
- Grain, softness, and imperfection are part of the sacred texture.
- The image should feel expensive because it is restrained.

## Color system

Primary palette:

- 墨黑 / ink black
- 深靛蓝 / deep indigo
- 雾蓝 / mist blue
- 月白 / moon white
- 冷灰 / cold gray
- 幽灵青 / ghost cyan
- 淡金 / pale gold

Accent palette:

- 暗金 / muted gold
- 微弱品红 / faint magenta
- 锈红 / rust red
- 银白 / silver white
- 冷青绿 / cold blue-green

Rule: use low saturation, controlled contrast, and very few accent colors.

## Texture system

Use selectively:

- low-resolution grain
- film noise
- digital scan noise
- xuan-paper fiber
- ink diffusion
- soft blur
- bloom
- halation
- subtle chromatic aberration
- dithering

Rule: never make the image too clean. A slightly imperfect surface helps the style feel sacred and distant.

## Density scale

### Minimal
Large negative space, one subject, one light source, very few objects. Best for high-end covers and spiritual images.

### Balanced
One clear subject plus controlled environment. Best for general prompt work.

### Narrative
More context, but still one emotional focus per frame. Best for manga, scenes, and series.
