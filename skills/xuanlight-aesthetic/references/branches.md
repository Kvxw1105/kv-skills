# Xuanlight Branches

## 1. 玄光·水墨 / Xuanlight Ink

Use for oriental ink-wash, xuan-paper texture, misty mountains, sparse landscape, cold pond, clouds, and poetic emptiness.

Core terms: 东方水墨, 宣纸晕染, 山水留白, 云雾, 孤峰, 寒潭, 月白雾蓝, 清冷诗性.

Risk: becoming generic guofeng illustration.  
Correction: add sacred light, low-resolution grain, solitude, and stronger emptiness.

## 2. 玄光·仙途 / Xuanlight Pilgrimage

Use for wuxia/xianxia, cultivators, swordsmen, pilgrims, monks, travelers, mountain paths, heavenly mandate, and spiritual journey.

Core terms: 武侠, 仙侠, 修行者, 剑客, 悟道, 孤峰, 天命垂照, 宿命感.

Risk: cheap ornate fantasy.  
Correction: reduce costume detail, reduce effects, use posture and light instead of ornament.

## 3. 玄光·灵核 / Xuanlight Soulcore

Use for ai-age spirituality, data soulism, translucent consciousness, glowing chest core, memory fragments, chat bubbles, code particles, and reconstructed identity.

Core terms: 数据灵魂, 空心意识体, 发光核心, 记忆残影, 代码光点, ai 灵魂感.

Risk: generic cyberpunk.  
Correction: reduce UI, reduce neon, emphasize poetry, solitude, and sacred light.

## 4. 玄光·废墟 / Xuanlight Ruins

Use for distant cities, black lakes, broken lights, abandoned skylines, reflective water, and gentle end-of-world feeling.

Core terms: 远方城市, 黑色湖面, 废墟边缘, 末日余光, 灯火微芒, 孤独站立.

Risk: generic night city poster.  
Correction: add sacred light logic, scale contrast, and poetic low-resolution texture.

## 5. 玄光·梦室 / Xuanlight Room

Use for quiet interiors, old rooms, window light, television glow, memory traces, private dreams, and ghostly stillness.

Core terms: 旧房间, 窗边天光, 电视微光, 回忆残像, 室内幽灵, 私人叙事.

Risk: becoming ordinary room illustration.  
Correction: make the light uncanny, sacred, or emotionally impossible.

## 6. 玄光·漫画 / Xuanlight Panels

Use for cinematic manga, storyboard, visual novel frames, sequential emotional storytelling, and series consistency.

Core terms: 剧情分镜, 电影静帧, 留白对白, 情绪镜头, 神性光源, 低清颗粒.

Risk: overcrowded panels or drifting style.  
Correction: one emotional beat per panel; keep palette, grain, light source, and character anchor consistent.

## Branch blending

Good combinations:

- 水墨 + 仙途: elegant eastern spiritual fantasy.
- 灵核 + 废墟: ai-age soul in a post-urban world.
- 梦室 + 灵核: private memory, ghost, and digital soul.
- 水墨 + 漫画: poetic silent panels.
- 仙途 + 漫画: destiny-driven wuxia/xianxia narrative.
