# Frontend Slides - ChatGPT Skill Package

This is a ChatGPT-compatible packaging of the public `zarazhangrui/frontend-slides` skill. It preserves the core Frontend Slides workflow and includes the core style presets, fixed 16:9 viewport CSS, HTML generation contract, animation reference, and lightweight utility scripts.

Source repository: https://github.com/zarazhangrui/frontend-slides

Note: the original repository is primarily packaged as a Claude Code plugin. This archive adds `agents/openai.yaml` and trims/adapts support files so it can be uploaded as a ChatGPT Skill package.
